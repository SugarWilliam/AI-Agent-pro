## 一、本次修改 Review（会话摘要）

### 1.1 V6.0 可选增强模块（V4.0 基础上融合）

| 模块 | 适用场景 |
|------|----------|
| 信息期权定价 | 持有观察仓且 E[r] 为负时 |
| 全天候组合 | 多标的持仓或询问分散时 |
| 三维退出网格 | 可补充阶梯表 |
| 3×3×3 压力测试 | 可替代或补充 3×3 |
| BMP-E 四维矩阵 | E 环境适应性，可选 |
| 时间止损强化 | 持有观察仓：观测期、观测价、到期日 |
| 贝叶斯+置信区间+动态更新 | 解释概率更新或量化不确定性时 |

### 1.2 禁止动作清单（V4.0 强制升级）

- 由「禁止动作条款」升级为「禁止动作清单」
- 阶梯式执行手册须含 3–5 条可执行禁止项，编号格式

### 1.3 概率处理分层

- **V4.0 基础层（必须）**：母概率 + 派生 + KDI 再归一化
- **V6.0 可选层**：贝叶斯 + 置信区间 + 动态更新（互补，不替代）
