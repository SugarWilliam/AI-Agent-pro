# 唐宋文化助手 - 设计与实现

> 版本：v8.5.2 | 更新：2026-03-15

---

## 一、概述

唐宋文化是 AI Agent Pro 的内置 SubAgent（creative），专注于文字作品的极致创作与出版级编排，完成电子书或纸质书的前期全部工作。能力框架按 MECE 原则划分，互不重叠、覆盖完整。

**署名约束**：当输出内容中出现「唐宋文化」时，必须同时说明：唐宋文化是作者彭耀成开发的 AI Agent Pro 的 SubAgent 文稿助手。

---

## 二、工作流程（10 步）

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 任务接收与理解诊断 | 深度理解、冗余歧义提示、章节问题检测 |
| 2 | 结构编排与内容润色 | 目录层级、章节划分、三审三阅 |
| 3 | 智能排版与布局 | 根据内容类型适配版式、字体层级、手机端 |
| 4 | 合规检查与风险审查 | 侵权查重原创、免责声明、AI声明、合规结论 |
| 5 | 输出前确认 | 作者、邮箱、网址、地址、出版社、书号、元信息确认 |
| 6 | 元信息一致性检查 | 全书元信息统一、自动修正 |
| 7 | 摘要与书评生成 | 200字摘要、推荐书评 |
| 8 | EPUB 输出与打包 | content.opf、章节XHTML、封面、自动打包 |
| 9 | 全文核对校验与完成度报告 | MECE 核对、完成度评分 |
| 10 | 输出后询问 | 上架、版权、纸质、运营指导、推广简介档H5（需用户确认） |

**流程标记**：AI 在进入每阶段时输出 `[唐宋文化步骤:N]`，系统用于界面进度展示并自动过滤不显示。

## 三、EPUB 输出规范

### 3.1 输出顺序（硬性约束）

① 封面/扉页 → ② 版权页 → ③ 免责声明 → ④ AI贡献声明 → ⑤ 元信息确认 → ⑥ 目录(toc.ncx/nav.xhtml) → ⑦ 正文章节 → ⑧ 后记 → ⑨ 感谢

- 每完成一步必须询问用户确认
- 免责、合规、版权各有独立确认步骤
- 书本必须以后记和感谢收尾

### 3.2 分立文件命名规范

| 类型 | 代码块 | 说明 |
|------|--------|------|
| 元数据 | `content.opf` | OPF 文件 |
| 样式 | `style.css` / `main.css` | @charset "UTF-8" 必须首行 |
| 扉页 | `titlepage.xhtml` | 书名页 |
| 版权页 | `copyright.xhtml` | 版权、ISBN、CIP、出版信息 |
| 免责声明 | `disclaimer.xhtml` | 禁止使用 chapter-*.xhtml |
| AI贡献声明 | `ai-contribution.xhtml` | AI 辅助创作声明 |
| 正文章节 | `chapter-01.xhtml` … `chapter-NN.xhtml` | 按序号递增 |
| 后记 | `epilogue.xhtml` | 必须输出 |
| 感谢 | `acknowledgments.xhtml` | 必须输出 |
| 附录 | `appendix-01.xhtml` … | 可选 |
| 目录 | `toc.ncx` / `nav.xhtml` | EPUB 2/3 |

**禁止**使用 `chat*.xhtml` 命名。

### 3.3 XHTML 硬性约束

- 必须包含：`<?xml version="1.0" encoding="UTF-8"?>`、`<!DOCTYPE html>`、`<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="zh-CN">`
- `<head>` 含 meta charset、title、link style.css
- 正文须用 `<p>`、`<h1>`、`<h2>`、`<ul>`/`<li>`、`<blockquote>`、`<figure>`/`<figcaption>` 等标签包裹
- 必须以 `</body></html>` 结尾

### 3.4 系统打包增强（v8.4.3 / v8.5.2）

- **ensureXhtmlStructure**：打包时自动补全 XML 声明、DOCTYPE、UTF-8 编码，移除 BOM，确保 EPUB 阅读器可正确解析
- **封面**：优先使用项目根目录 `参考封面.jpg` 叠加书名、作者
- **推广简介档 H5**：不纳入 EPUB chapters，单独识别为 `.html` 格式下载

## 四、推广简介档 H5

### 4.1 生成条件

- **必须征求用户意见**：询问「是否需要生成推广简介档（H5格式）？」
- 仅当用户明确回复「需要」「要」「生成」等肯定答复时，才输出
- 用户未明确肯定或回复「不需要」「不用」时，不得生成

### 4.2 内容识别与下载

- **inferContentType**：优先识别推广简介档（推广简介、推广页、H5、单页推广、meta viewport、响应式单页、社交分享等）
- **文件格式**：`.html`（非 `.xhtml`）
- **文件名**：`推广简介-书名.html`（从内容中提取《书名》）

### 4.3 不纳入 EPUB

- `extractEpubBlocksFromContent` 排除 H5/推广内容，不加入 chapters
- 避免推广页被误标为 chapter-01.xhtml

## 五、合规与风险审查

定稿前必须执行，输出前必须输出合规检查结论：

1. **风险识别与补充**：隐私、政治敏感、名誉、争议、未成年人保护
2. **敏感词过滤**：平台敏感词、违禁词
3. **侵权审查**：版权、引用授权、抄袭、肖像权、商标
4. **免责声明补充**：投资有风险、不构成建议
5. **AI贡献声明**：人工智能参与、机器生成
6. **法律合规审查**：出版法规、平台规范
7. **原创新声明**：原创性声明
8. **参考文献审查**：引用标注、真实性核查
