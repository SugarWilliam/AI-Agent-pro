## 一、V4.0 强制 8 段结构（必须）

| 段 | 标题 | 必须内容 |
|----|------|----------|
| ① | **核心结论（概率-结论）** | 概率-结论格式；**即时行动指令**（非仅状态描述；高优先级风险触发时须可执行指令）；可融入期望值表述 |
| ② | **数据层与溯源** | **现金流分析**专节或明确标题；**数据溯源表** |
| ③ | **立体分析与量化矩阵** | **三维坐标**（X/Y/Z 显式小标题）；矩阵内**动态调整公式**；**DCF 敏感性分析**（WACC/g 表，与 P 维/阶梯显式衔接） |
| ④ | **决策路径图** | Mermaid 流程图 |
| ⑤ | **KDI** | **动态情绪因子**与锚定公式 |
| ⑥ | **压力测试** | 魔鬼代言人 + 反驳所需证据 + **3×3 估值矩阵**（估值类禁止省略）；有用户成本/持仓时须**个性化冲击力**表述 |
| ⑦ | **阶梯式执行手册** | **时间止损**；**禁止动作清单**（独立小节或阶梯表内禁止条款列，3–5 条，编号格式）；适用时**必须**含**阶梯0：立即执行** |
| ⑧ | **报告元信息** | 使用指南、版本日志、免责声明 |

## 二、必须体现（硬性）

- **现金流分析**：OCF/FCF/OCF÷净利/Capex/营运资本（独立小节或明确标题）
- **3×3 估值压力测试矩阵**：估值类报告不可省略为文字概括
- **三维坐标定位**：X/Y/Z 显式小标题
- **时间止损**：执行手册中与价格/逻辑止损并列，含日历或事件节点
- **DCF 敏感性分析**：估值类须含 WACC/g 敏感性表，与决策矩阵 P 维、决策链阶梯显式衔接
- **禁止动作清单**：阶梯式执行手册须含 3–5 条可执行禁止项，编号格式便于逐项对照
- **动态情绪因子**：KDI 或情景中纳入可更新情绪指标
- **期望值思维**：独立小节 `#### **期望值思维（工程化落地）**`，E(结果)=ΣP×结果
- **霍华德·马克斯**：独立小节 `#### **霍华德·马克斯 / 橡树思想**`，第二层次思维、周期、永久损失 vs 波动、安全边际与逆向

## 三、概率处理分层

| 层级 | 内容 | 性质 |
|------|------|------|
| **V4.0 基础层** | 母概率 + 派生 + KDI 再归一化 | **必须**：保证程序化、可复现、可回测 |
| **V6.0 增强层** | 贝叶斯 + 置信区间 + 动态更新 | **可选**：解释更新逻辑或量化不确定性时启用 |

## 四、V6.0 可选增强模块（当场景适用时建议输出）

| 模块 | 适用场景 |
|------|----------|
| **信息期权定价** | 已减仓/持有观察仓且 E[r] 为负时 |
| **全天候组合** | 多标的持仓或询问分散/组合时 |
| **三维退出网格** | 可补充阶梯表，按价格/基本面/时间三维组织，明确优先级 |
| **3×3×3 压力测试** | 需更深度量化时，可替代或补充 3×3 |
| **BMP-E 四维矩阵** | 可选增加 E（环境适应性）维度 |
| **时间止损强化** | 持有观察仓时：观测期、观测价、到期日、触发条件、执行动作 |
| **贝叶斯 + 置信区间 + 动态更新** | 解释概率更新逻辑或量化不确定性时：P(情景)=X% [下界%-上界%] |
