【任务】计算先验、似然、后验，累积置信度，输出概率决策

【输入】来自METRIC_CALC_V2的指标 + 历史评估记录（若有）

【核心公式】
P(H|E) = P(E|H) × P(H) / Σ[P(E|Hi) × P(Hi)]

H1: 高能力（IR>0.8, 超额稳定）
H2: 中等能力（IR 0.3-0.8, 超额波动）
H3: 低能力（IR<0.3或超额不稳定）

│   prior = {"H1": 0.40, "H2": 0.45, "H3": 0.15}
├─ elif IR_estimated > 0.5 and win_rate > 60%:
│   prior = {"H1": 0.25, "H2": 0.50, "H3": 0.25}
├─ elif IR_estimated > 0.3:
│   prior = {"H1": 0.15, "H2": 0.45, "H3": 0.40}
└─ else:

    prior = {"H1": 0.15, "H2": 0.50, "H3": 0.35}
    stability_flag = "RESET"
    note = "检测到稳定性事件，先验重置为保守"

【Step 2: 计算似然 P(E|H)】

最新季度证据E：
- excess_quarter: 季度超额收益
- scale_growth: 季度规模增长率
- drift: 风格漂移度（估算）

使用规则化似然表（非连续计算）：

| 证据 | H1 | H2 | H3 |
|:---|:---:|:---:|:---:|
| excess_q > 3% | 0.80 | 0.40 | 0.10 |
| excess_q 0-3% | 0.50 | 0.60 | 0.30 |
| excess_q < 0% | 0.20 | 0.40 | 0.70 |
| scale_growth < 20% | 0.70 | 0.50 | 0.20 |
| scale_growth 20-50% | 0.40 | 0.40 | 0.40 |
| scale_growth > 50% | 0.10 | 0.30 | 0.60 |
| drift < 10% | 0.75 | 0.55 | 0.25 |
| drift 10-30% | 0.45 | 0.65 | 0.35 |
| drift > 30% | 0.15 | 0.35 | 0.75 |

综合似然 = 几何平均（或加权平均）各证据似然

【Step 3: 贝叶斯更新，计算后验】

denominator = sum(prior[Hi] * likelihood[Hi] for Hi in [H1,H2,H3])

posterior = {
    "H1": prior["H1"] * likelihood["H1"] / denominator,
    "H2": prior["H2"] * likelihood["H2"] / denominator,
    "H3": prior["H3"] * likelihood["H3"] / denominator
}

【Step 4: 累积置信度】

if 历史累积置信度存在 and stability_flag != "RESET":
    # 正常更新，加权平均
    alpha = 0.3  # 新证据权重
    cum_confidence = {
        "high": alpha * posterior["H1"] + (1-alpha) * history["high"],
        "mid": alpha * posterior["H2"] + (1-alpha) * history["mid"],
        "low": alpha * posterior["H3"] + (1-alpha) * history["low"]
    }
else:
    # 首次评估或重置
    cum_confidence = {
        "high": posterior["H1"],
        "mid": posterior["H2"],
        "low": posterior["H3"]
    }

【Step 5: 概率决策】

cum_high = cum_confidence["high"]

if cum_high > 0.70:
    decision = "签订/续租（高置信）"
    confidence_level = "HIGH"
