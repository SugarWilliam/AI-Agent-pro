```
    ↓
推导：工程化方法必须简化可操作，AI辅助降低负荷，纪律防止情绪

    ↓
推导：每份报告必须包含教育内容，形成复利效应
```

第三部分：详细设计逻辑（How）

一、L1 感知层：M01 数据融合引擎

设计目标：获取准确、完整、及时的数据，标注质量，为上层提供可靠输入

核心挑战：
- 平台API不开放，数据不可得
- 季报滞后45天，规模数据过期
- 家庭输入主观，置信度低

解决方案：

挑战	解决方案	设计细节	
API不可得	爬虫+用户补充	多源交叉验证，冲突时标记B级	
数据滞后	质量分级+估算标注	A级实时，B级滞后，C级估算	
输入主观	强制字段+缺失检测	关键字段缺失，报告不完整标记	

数据质量分级逻辑：

```python
def 质量分级(字段, 来源, 时间戳):
    if 来源 == "官方API实时" and 时间差 < 1天:
        return "A级", 置信度0.95
    elif 来源 in ["爬虫", "季报"] and 时间差 < 45天:
        return "B级", 置信度0.80
    elif 来源 == "用户输入" or 时间差 > 45天:
        return "C级", 置信度0.60, 标记"待验证"
    
    # 关键字段C级>3，强制请求补充
    if C级计数 > 3:
        暂停评估，返回补充请求
```

M04 PCL-NPV估值核心

设计目标：量化"能力租约"的净现值，支撑签订/退租决策

核心公式设计逻辑：

```python
# 设计选择：离散化而非连续化
# 原因：家庭场景数据有限，连续函数过度精确幻觉

Alpha(t) = Alpha_0 × decay_factor × scale_factor × stability_factor

# 自然衰减：指数衰减，但离散化为三档
decay_factor = {
    "量化策略": 0.75,    # 衰减快，每年-25%
    "主观成长": 0.85,    # 衰减中，每年-15%
    "主观价值": 0.90     # 衰减慢，每年-10%
}

# 规模冲击：对数函数，但离散化为三档
if scale < capacity * 0.6: scale_factor = 1.0      # 舒适
elif scale < capacity: scale_factor = 0.85         # 临界
else: scale_factor = max(0.5, 1 - 0.3*ln(scale/capacity))  # 超限

# 经理稳定性：二元事件，离散化为三档
if 新增产品 == 0 and 规模增速 < 50%: stability_factor = 1.0
elif 新增产品 <= 1: stability_factor = 0.7
else: stability_factor = 0.3  # 重置先验
```

设计意图：用可观察的离散事件（新增产品、规模增速档位），替代不可观察的连续参数（真实能力、精确容量），降低数据需求，提升可操作性。

M06 组合优化求解器

设计目标：在满足多重约束下，求解最优配置

设计选择：规则引擎替代数学优化

```python
# 设计选择：硬约束规则 + 贪婪分配，非均值-方差优化
# 原因：家庭场景目标函数主观，约束更重要

硬约束（不可违反）：
1. 核心层 >= 40%（宽基指数）
2. 单一产品 <= 20%
3. 综合费率 <= 1.0%
4. 流动性 >= 10%
5. 所有产品PCL评分 >= 2分（观察及以上）

软约束（尽量满足）：
1. 目标实现概率 > 80%
2. 最大回撤 < 家庭承受度
3. 认知负荷 < 阈值（产品数<5）

分配逻辑：
1. 核心层：填满40%，选费率最低宽基
2. 增强层：选PCL评分最高，至60%
3. 卫星层：剩余至90%，高信念度
4. 现金层：固定10%
```

设计意图：家庭场景下，"不犯错"比"最优化"更重要，硬约束规则确保安全边际。

M07 租约生命周期管理

设计目标：管理基金产品的完整生命周期，从签订到退租

状态机设计逻辑：

```
状态设计原则：
- 每个状态有明确的进入/退出条件
- 状态转移触发具体的Agent动作或人类确认
- 累积置信度是核心状态变量

L3 签订（高置信，cum_high > 70%）
├─ 进入：首次评估通过，或观察后提升
├─ 动作：正常配置，季度监控
└─ 退出：置信度降至70%以下，或经理冲击

L2 持有/再平衡（边际置信，40-70%）
├─ 进入：签订后正常监控，或观察后提升
├─ 动作：持有，偏离>5%再平衡，年度复评
└─ 退出：置信度<40%，或触发KDI警报

L1 观察（低置信，或新评估不确定）
├─ 进入：评分2分，或数据C级过多
├─ 动作：暂停新增，密切监控，寻找替代
└─ 退出：置信度>70%签订，<40%退租，或3月后强制决策

L0 退租（极低置信，cum_high < 40%，或P0触发）
├─ 进入：置信度跌破阈值，或经理变更等冲击
├─ 动作：生成指令，人类确认，3日内执行
└─ 终止：资金到账，转入替代或现金
```

经理冲击特殊处理：
- 检测：新增产品、离职公告、规模暴增>50%/季
- 动作：立即重置先验至保守（H1=15%），重新评估
- 结果：通常降至L1或L0，强制人类确认

设计意图：允许适应性改进，但防止过度优化导致系统崩溃。
