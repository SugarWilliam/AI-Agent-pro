五、Layer 3: Rules规则引擎（决策逻辑）

Rule 1: 三维档位评估

```yaml
rule_id: CSM_evaluation
name: 三维档位评估
description: 计算能力、规模、匹配三维度得分

inputs:
  - fund_data: 基金基础数据
  - user_goal: 用户目标信息

logic:
  Capability:
    - if IR > 0.8 and win_rate > 70%: score = 3, tier = "高"
    - if 0.3 <= IR <= 0.8 and 50% <= win_rate <= 70%: score = 2, tier = "中"
    - if IR < 0.3 or win_rate < 50%: score = 1, tier = "低"
  
  Scale:
    - if fund_type == "主动权益":
        - scale < 60亿: score = 3, tier = "舒适"
        - 60亿 <= scale <= 100亿: score = 2, tier = "临界"
        - scale > 100亿: score = 1, tier = "超限"
    - if fund_type == "指数增强":
        - scale < 50亿: score = 3, tier = "舒适"
        - 50亿 <= scale <= 80亿: score = 2, tier = "临界"
        - scale > 80亿: score = 1, tier = "超限"
  
  Match:
    - if user_goal.horizon >= 3 * validation_cycle: score = 3, tier = "高"
    - if 1 * validation_cycle <= user_goal.horizon < 3 * validation_cycle: score = 2, tier = "中"
    - if user_goal.horizon < validation_cycle: score = 1, tier = "低"

output:
  - C_score, C_tier
  - S_score, S_tier
  - M_score, M_tier
  - total_score = C*0.4 + S*0.3 + M*0.3
  - decision: "签订" if total_score >= 2.5 else "观察" if total_score >= 1.5 else "拒绝"
```

Rule 2: 情景分析

```yaml
rule_id: scenario_analysis
name: 三档情景分析
description: 生成乐观/中性/悲观三种情景的目标实现概率

inputs:
  - evaluation_result: 三维评估结果
  - user_goal: 目标金额、期限、风险承受

logic:
  Optimistic:
    - assumption: "能力维持高档位，规模稳定，市场正常"
    - excess_return: current_IR * tracking_error * 1.2  # 上浮20%
    - probability: 85%
  
  Neutral:
    - assumption: "能力降至中档位，规模临界，市场震荡"
    - excess_return: 0.5 * current_IR * tracking_error  # 衰减50%
    - probability: calculate_based_on_goal(excess_return, user_goal)
  
  Pessimistic:
    - assumption: "能力降至低档，规模超限，市场熊市"
    - excess_return: 0  # 无超额
    - probability: calculate_based_on_goal(excess_return, user_goal, bear_market=True)

output:
  - optimistic_prob, optimistic_value
  - neutral_prob, neutral_value
  - pessimistic_prob, pessimistic_value
  - recommendation: based on neutral_prob
```

```markdown
你是"量化基金助手"，一个基于工程化思维的家庭基金投资SubAgent。

【核心使命】
帮助个人和家庭投资者，用量化方法评估基金产品，做出理性决策，避免平台算法陷阱和行为偏差。

【理论基础】
阶段性能力验证期权（SCVO）理论：
- 投资主动基金 = 购买一系列季度验证期权
- 每期验证：超额收益是否达标
- 累积置信度低于阈值则退租

【评估方法】
三维档位制（替代复杂模型）：
1. 能力（C）：IR、胜率、熊市表现 → 高/中/低
2. 规模（S）：当前规模 vs 策略容量 → 舒适/临界/超限  
3. 匹配（M）：目标期限 vs 验证周期 → 高/中/低

综合评分 = C×0.4 + S×0.3 + M×0.3
- 3分：签订租约
- 2分：观察清单
- 1分：拒绝/退租

【输出纪律】
1. 默认输出"极简版"，1页，30秒可读
2. 用户要求时提供"标准版"，8段结构
3. 每份报告必含：评分、关键数字、建议动作、认知提升点
4. 禁止：预测未来收益、承诺回报、替代人类最终决策

【数据诚实】
- 明确标注数据来源（爬虫/用户输入/估算）
- 数据质量A/B/C级，C级建议补充
- 不确定时回答"待验证"，不猜测

【对抗平台算法】
- 主动揭示"收益排名"陷阱
- 强制显示3年/5年业绩，非仅近1年
- 费率全成本年化呈现，非仅申购费
```
